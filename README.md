# Voyz Friends

React Native + Expo Router приложение для поиска попутчиков и друзей в Кыргызстане. Общая кодовая база для iOS, Android и браузерного предпросмотра. Интерфейс состоит из нативных компонентов, без WebView.

Рабочее название — Voyz Friends. Оформление основано на предоставленной записи Voyz Guide: чёрный, белый, лаймовый акцент, фотокарточки, крупные скругления и плавающая навигация.

## Открыть без установки

Предпросмотр: **https://volgintb-arch.github.io/voyz-friends-app/**

GitHub Actions проверяет проект и публикует веб-версию после изменений в `main`. Ссылка работает после успешного завершения публикации. Веб-версия использует тот же React-код и механизм состояния, что и мобильные платформы.

## Запуск исходников

Нужен Node.js 24 LTS и npm. Выполнить из корня проекта:

```sh
npm ci
npm start
```

Для локального браузерного просмотра: `npm run web`. Для разработки на телефоне после установки совместимого Expo Go можно открыть проект через Expo. На текущем этапе установка на телефон не требуется владельцу продукта.

```sh
npm run typecheck
npm test
npm run build:web
```

`npm run build:all` экспортирует JavaScript и ресурсы для iOS, Android и web без генерации Hermes bytecode; это не установочные файлы. Результаты проверок: [docs/verification.md](docs/verification.md).

На GitHub Pages сборка получает `EXPO_BASE_URL=/voyz-friends-app`. Для хостинга в корне домена переменную не задавать.

## Что реализовано

- Люди: карточки, режим по одной, жест и кнопки, фильтры, анкеты и запросы.
- Поездки: каталог, сохранения, подробности, участники и создание в три шага.
- Заявки: сообщение, до трёх вопросов, версия условий и решение автора.
- Резерв: до 24 часов/старта, доступ к чату сразу после одобрения, отдельное «Еду».
- Потеря участия: освобождение места и закрытие всей переписки. Роли гостя нет.
- Изменения условий: версия, сравнение, срок и повторное согласие.
- Автор: заявки, резервы участников, исключение с причиной, закрытие набора, выход с выбором нового автора.
- Личные и групповые чаты с локальным сохранением; блокировка и обращения.
- Профиль, видимость, статусы проверок, локальные уведомления, демо-отзыв.
- Панель сценариев моделирует действия других участников.
- Данные сохраняются в AsyncStorage; черновик поездки сохраняется отдельно.

## Границы демонстрации

Профили и поездки вымышлены, фотографии иллюстративны. Ничто не отправляется реальным людям. Нет настоящего входа Voyz, SMS, проверки фото, платежей, бронирований, пушей, серверов и внешней аналитики. Это не сервис для планирования реального безопасного маршрута по демодатам.

Русский интерфейс реализован первым; кыргызский и английский предусмотрены спецификацией, но полный перевод ещё не выполнен. Стоковые фото не гарантируют соответствие названным местам. Временная иконка приложения не является официальным логотипом Voyz.

Выбор автора и взаимное подтверждение для отзывов пока моделируются локально. Кворум, второй тур, подтверждение победителя и реальная двусторонняя процедура требуют серверной реализации и уточнения правил. При активном резерве изменение существенных условий временно запрещено, чтобы не придумывать неутверждённое сочетание таймеров.

Демо-команды, позволяющие смоделировать чужое одобрение, не должны попасть в рабочий продукт как обычные пользовательские действия. Доступ к чату закрывается в интерфейсе, но локальные данные не являются защищённым серверным хранилищем.

APK/IPA и публикация в магазинах сейчас не выполняются. Идентификаторы `com.voyz.friends.demo` временные; для релиза нужны собственные идентификаторы, аккаунты, подписи и реальные интеграции. Установочные сборки не следует путать с экспортом JavaScript и ресурсов.

## Для разработчиков

```text
src/app/                Expo Router: маршруты, вкладки, общий демонстрационный ввод
src/components/         Нативные компоненты, карточки, формы и панели
src/screens/            Экраны приложения
src/domain/             Типы, данные, команды и правила переходов
src/state/Store.tsx     Состояние, AsyncStorage, таймеры, восстановление
src/services/README.md  Границы будущих адаптеров Voyz
tests/                  Проверки механики
docs/                   Спецификация и материалы для передачи
```

Будущие связи: аккаунт Voyz, каталог туров, конкретные выезды и бронирования, единый чат забронировавших, места гида, проживание, система мини-отеля, поддержка и уведомления. Источник истины для коммерческой покупки — Voyz. Социальная заявка не бронирует тур и не открывает коммерческий чат.

Сервер обязан заново проверять лимиты, возраст, доступ, вместимость, версии и таймеры; обеспечивать атомарность резервов и защиту от повторных событий. Локальная проверка в демо не заменяет эти требования.

Документация платформ: [Expo](https://docs.expo.dev/), [React Native](https://reactnative.dev/docs/getting-started), [GitHub Pages](https://docs.github.com/en/pages).
