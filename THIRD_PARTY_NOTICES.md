# Сторонние материалы

Проект создан с использованием официального шаблона Expo. Уведомление о лицензии исходного шаблона сохранено в `docs/expo-template-license.txt`; оно относится к материалам Expo. Отдельная лицензия на собственный продукт Voyz этим файлом не устанавливается.

Зависимости React, React Native, Expo, React Navigation и другие пакеты сохраняют собственные лицензии. Точные версии зафиксированы в `package-lock.json`.

Источники иллюстративных стоковых фотографий указаны в `assets/photos/sources.json`. Анкеты и истории вымышлены. Фотографии не подтверждают личность и не гарантируют соответствие указанным местам.

Дизайн-референс Voyz Guide предоставлен владельцем продукта. Название Friends и временная иконка используются для демонстрации; официальный брендбук и оригинальный векторный логотип не предоставлены.
