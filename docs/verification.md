# Проверка React Native версии

30 октября 2026 года.

- TypeScript: проверка типов без ошибок.
- Expo ESLint: проверка без ошибок и предупреждений.
- 12 тестов механики: заявки, резервы, запрет переполнения и повторного одобрения, подтверждение, истечение, выход, версии условий, исключение, личные запросы и лимит, права автора, выбор нового автора, отсутствие локальной коммерческой брони.
- Браузерная сборка Expo Router экспортируется для GitHub Pages с базовым путём `/voyz-friends-app`.
- JavaScript и ресурсы экспортированы для iOS, Android и web с `--no-bytecode`. Это проверка сборки кода, не APK/IPA и не запуск на устройствах.
- Автоматизированная проверка браузерного интерфейса: заявка → одобрение → резерв → «Еду» → сообщение в чате; новое согласие на бюджет; выход с потерей доступа; личный запрос; сохранение анкеты после перезагрузки.
- Проверка адаптивности на ширинах 320, 375, 768 и 1440 пикселей.

Границы: реальных серверов, аккаунтов Voyz, проверок личности, платежей и пушей нет. Нативные установочные сборки и тесты на физических iOS/Android не выполнялись: текущая задача владельца — репозиторий и ссылка в браузере. Локальная генерация Hermes bytecode на Windows не завершилась; проверка экспорта всех платформ выполнена без bytecode. Будущая подписанная нативная сборка потребует отдельной проверки в среде сборки.
